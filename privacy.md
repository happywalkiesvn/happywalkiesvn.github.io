# Privacy Policy - Sao luu may tinh (Happy Walkies)

This app is a private, internal backup tool used only by Happy Walkies (happywalkiesvn@gmail.com).

- It uploads files from Happy Walkies' own computer to Happy Walkies' own Google Drive.
- It only accesses Google Drive files that the app itself created (scope: drive.file).
- No data is shared with, sold to, or sent to any third party. No data is stored anywhere other than the owner's computer and the owner's Google Drive.
- Access can be revoked at any time at https://myaccount.google.com/permissions

Contact: happywalkiesvn@gmail.com

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
