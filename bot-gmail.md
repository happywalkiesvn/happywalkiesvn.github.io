# Privacy Policy - Bot tro ly Gmail

This app is a private, internal assistant used only by its owner (Happy Walkies, happywalkiesvn@gmail.com, and the owner's personal Gmail account).

It only READS Gmail (scope: gmail.readonly). It cannot send, delete, or change any email.

Email content is used only to create a short daily summary that is sent to the owner's own Telegram chat. Processing runs on the owner's own Cloudflare account (Cloudflare Workers AI). Email content is not stored long-term.

No data is sold to, shared with, or sent to any other third party.

Access can be revoked at any time at https://myaccount.google.com/permissions

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
